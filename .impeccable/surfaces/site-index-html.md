# Surface Brief: site/index.html

- **Mode:** Persuade
- **Audience:** Linux DJs (bedroom and club) using Native Instruments Traktor controllers (MX2, S4 MK3, S2/S3, X1/Z1/F1/D2/S8/S5) or class-compliant MIDI gear (DDJ-FLX4), looking for a native Linux DJ workstation without Wine or subscriptions.
- **Job:** Evaluate every real capability of ReTraktor via live app screenshots and technical specs, then install via `.deb`, `./install.sh`, or GitHub source.
- **Primary Action:** Download `retraktor_latest_amd64.deb`, copy the `./install.sh` / `git clone` command, or open the GitHub repo (`adamtdm/ReTraktor`).
